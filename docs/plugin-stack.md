# Plugin stack

What I install on every WordPress build, and why. Fewer, better plugins beat a long list.

## SEO
- **Rank Math** — full SEO suite: titles/metas, sitemaps, schema, redirections. (Yoast is a fine alternative.)

## Security
- **Wordfence** — firewall + malware scanning. Configure the firewall in "extended protection" mode.

## Performance
- **LiteSpeed Cache** (on LiteSpeed servers) or **WP Rocket** — page caching, object cache, critical CSS.
- **ShortPixel** or **Imagify** — image compression with WebP/AVIF conversion.

## Backups
- **UpdraftPlus** — scheduled off-site backups (Google Drive / S3). Test restores quarterly.

## Forms
- **Fluent Forms** — lightweight, no bloat.

## Rule of thumb
If a plugin hasn't been updated in 6+ months or has fewer than 10k installs, find an alternative. Every plugin is attack surface and page weight — audit yearly.
